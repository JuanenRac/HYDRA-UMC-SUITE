# juanenpnp: independent editable mesh set

Created 2026-09-12 as a copy of lumenpnp STL assets (167 files).
Upstream authorship/export provenance and license notices remain in ATTRIBUTION.txt.
No CAD changes have been applied to this initial copy.

This directory is loaded independently. Editing it must not modify lumenpnp
or another variant. Keep STL units in mm, assembly coordinates and filenames.
STUDIO loads these STL files directly; no GLB conversion is needed here.
SUITE uses the matching folder under assets/meshes.

The common rig is an initial visual structure, not verified CNC/laser hardware
or collision/motion safety. Record later geometric changes below.
